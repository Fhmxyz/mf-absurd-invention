# One-Sentence Absurd Invention Pitch

A make.fun entry for the [One-Sentence Absurd Invention Pitch bounty](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a).
`main.py` writes one sentence to `/output/entry.txt`:

> Introducing the Doorway Rewind, a doormat that records your last thought
> and replays it as you cross the threshold, for everyone who has ever
> opened the fridge hoping it remembered why they came.

Run it with `python3 main.py`.
